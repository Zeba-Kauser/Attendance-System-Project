# College Attendance Management System

## 📌 Project Overview
The College Attendance Management System is a web-based project designed to simplify student attendance tracking. It provides a simple interface to manage student records and maintain attendance information efficiently.

## ✨ Features
- View student details.
- Mark students as Present or Absent.
- Track attendance records.
- Simple and user-friendly interface.
- Organized attendance data.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🎯 Project Objective
To develop a simple web application that makes college attendance tracking easier, faster, and more organized.
